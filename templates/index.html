Which files can I upload? {% if dwg_supported %}

.dxf and .dwg both work. DWG is Autodesk's closed binary format, so it's converted to DXF server-side first (via LibreDWG) — coordinates, layers, colours and the drawing's declared units are all carried across, so the scale stays exact. Very new or unusual DWG revisions occasionally fail to parse; if that happens, do Save As → DXF in your CAD program and upload that.

{% else %}

Upload .dxf files. DWG is Autodesk's closed binary format and DWG support isn't installed on this server — convert it to DXF first with the free ODA File Converter, or Save As → DXF in AutoCAD, BricsCAD or LibreCAD. DXF is lossless, so accuracy and scale are preserved.
